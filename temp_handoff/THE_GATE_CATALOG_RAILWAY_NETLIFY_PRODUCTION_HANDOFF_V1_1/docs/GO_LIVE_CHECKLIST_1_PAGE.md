# The Gate Catalog — IT go-live checklist

1. **Create Railway service and volume.** One service, exactly one instance/replica, volume mounted `/runtime`. This topology can have a short availability gap during redeploy. **Expected:** Railway shows the volume attached to the single instance. **STOP/ROLLBACK:** do not deploy if mount differs, replica count exceeds one or another service shares it.
2. **Enter secrets in Railway UI.** Use `.env.railway.example`; keep all placeholders out. **Expected:** variables saved privately, API keys distinct. **STOP:** never paste secrets into chat/Git/Netlify/HTML.
3. **Share Google Sheet.** Share only spreadsheet `1kWGZy7Stnrs842lnt36Y_3ROO-t_pfNvRcz-cVwU1Eg` to the service-account email as Viewer. **Expected:** service account can read; cannot edit. **STOP:** wrong file or Editor access.
4. **Deploy disabled and test liveness/offline preflight.** Keep `KIOT_CATALOG_SYNC_ENABLED=false`, deploy, request `/livez`, then run `--preflight-only`. **Expected:** 200 `{"status":"alive"}`, offline PASS, zero Kiot sync/Google Sheet call. **STOP/ROLLBACK:** non-200, upstream call before approval, missing volume or crash-loop.
5. **Owner approves read-only activation; run initial manual build.** Run Kiot preflight, initial sync and `--build-once`. **Expected:** business methods GET only, website LKG created without changing the source cutoff. **STOP:** contract drift, write method, Google error or partial build.
6. **Verify before enabling worker.** Check `/health`, `service-status`, item count and at least three Owner-selected SKUs. **Expected:** current source cutoff, SALE price, correct image/name/availability, no exact inventory. Only then set `KIOT_CATALOG_SYNC_ENABLED=true` and redeploy. **STOP:** mismatch, stale/503 or unknown count.
7. **Safely merge exact Netlify rewrite.** Backup/read existing `_redirects` and `netlify.toml`; insert only `/api/catalog ... /v1/website/catalog 200!` before SPA catch-all. **Expected:** old rules preserved, no wildcard. **STOP:** overwrite, `/api/*`, internal or keyed route exposure.
8. **Install JS/drop-in and deploy Preview.** Copy the provided assets/markup. **Expected:** Preview renders valid catalog or friendly degraded state; no false empty success. **ROLLBACK:** restore the `_redirects` backup and remove only catalog assets/markup.
9. **Inspect browser security.** DevTools must show same-origin `/api/catalog` only. **Expected:** no API key, Google/Kiot credential, raw Railway internal/source route or customer data in HTML/JS/network/storage. **STOP:** any secret/internal exposure.
10. **Promote and retain rollback.** Promote the verified Netlify Preview. **Expected:** public catalog works and monitoring timestamps advance. **ROLLBACK:** restore prior Netlify deploy and prior Railway release; never delete `/runtime` volume.
